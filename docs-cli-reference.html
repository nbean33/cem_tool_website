CLI and automation

CLI reference

List of all verbs and flags for machshev command line use. Workflows and examples are on CLI overview, spec details on Scripting and specs.

Local verbs

machshev benchmark

Run CPU and/or CUDA benchmark pass. The command uses bundled geometry and prints one JSON result to stdout.

FlagValueDefaultMeaning
--backendcpu / cuda / bothbothBackend ladder to run (default: both available backends).
--device-indexDEVICE_INDEX|| Reported GPU index for CUDA cases.
--qualityapproximate / standard / precisestandardStep count: approximate 100, standard 1000, precise 10000.
--single-size, --sizeSIZE|| Run only one memory rung: 100MB, 1GB, 3GB, 10GB, 20GB, 40GB, 80GB, 100GB, 150GB, or 200GB.

machshev auth

Manage the local license cache. Activation binds the key + machine id pair on the Machshev Labs licensing service and persists the result for both the desktop UI and CLI. The auth subcommand does not require Pro.

FlagValueDefaultMeaning
--license-keyLICENSE_KEY|| License key to activate on this machine. Format: the same string you received by email after subscribing. Case is normalized to upper, surrounding whitespace stripped.
--machine-nameMACHINE_NAME|| Optional human-readable label for this machine (shown in the account dashboard's seat list). Defaults to the host name.
--status||Print the cached license state and perform a fresh server check. Default action when no other flag is given.
--deactivate||Release this machine's seat on the licensing service and clear the local cache.

machshev run

Run one project or all projects in a folder (sequential). Exit codes on both forms: 0 all projects ran clean, 1 at least one failed at runtime, 2 no runtime failures but at least one was refused by validation (the same fixable-invocation code validate and --dry-run use). A folder batch keeps going past a bad project and reports the worst outcome.

FlagValueDefaultMeaning
--project, -pPROJECT|| Path to a single .rfsim/.emflux project file.
--folder, -fFOLDER|| Path to a folder containing .rfsim/.emflux projects.
--jobJOB_FILE|| Path to a YAML/JSON JobSpec.
--recursive||When using --folder, search recursively.
--backendBACKEND|| Backend to run: cpu, cuda, or a path to a backend executable. Overrides the job file's backend field. If omitted, auto-detected next to the app (CUDA preferred).
--air-around, --air-around-mmAIR_AROUND_MM|| Override FDTD air around (mm).
--air-above, --air-above-mmAIR_ABOVE_MM|| Override FDTD air above (mm).
--air-below, --air-below-mmAIR_BELOW_MM|| Override FDTD air below (mm).
--dx, --dx-mmDX_MM|| Override dx (mm).
--dy, --dy-mmDY_MM|| Override dy (mm).
--dz, --dz-mmDZ_MM|| Override dz (mm).
--meshuniform / graded|| Mesh-style override for this run. Both choices explicitly select Ratio strategy while retaining any Custom profile as an inactive draft. 'uniform' sets x/y/z multipliers to 1, so dx/dy/dz are literal everywhere. 'graded' uses the saved per-axis Ratio multipliers. Default: use the project's saved strategy.
--freq-min, --freq-min-mhzFREQ_MIN_MHZ|| Override frequency band minimum in MHz.
--freq-max, --freq-max-mhzFREQ_MAX_MHZ|| Override frequency band maximum in MHz.
--boundary-conditionBC_ALL|| Override boundary condition (e.g. PML8).
--eps-rEPS_R|| Override dielectric eps_r.
--thickness, --thickness-mmTHICKNESS_MM|| Override dielectric thickness (mm).
--loss-tangentLOSS_TANGENT|| Override every dielectric layer's loss tangent (tan d). 0 is lossless. FR4 is typically ~0.02, low-loss substrates ~0.001-0.005.
--loss-tangent-atLOSS_TANGENT_REF_HZ|| Override every dielectric layer's loss reference frequency, in Hz: the frequency its loss tangent is exact at. Required alongside a positive --loss-tangent on a stackup that carries no reference. It may lie outside the simulated band.
--fft-length-multiplier, --fft-multFFT_LENGTH_MULTIPLIER|| Force override FFT length multiplier used for S-parameter post-processing (zero-padding). Must be >= 1.
--qualityQUALITY|| Auto-mode quality. Name ("low"/"medium"/"high"/"very-high"/"med-high") or float in [0,3]. The effective project mode must be auto.
--quality-fracQUALITY_FRAC|| Auto-mode quality as a slider fraction in [0, 1] (multiplied by 3).
--sim-modeauto / advanced|| Force simulation mode. Use auto with --quality. Advanced keeps the explicit settings.
--convergence, --no-convergence||Enable or disable the mesh-convergence study. When enabled the run repeats up to conv_max_passes backend passes, refining dx/dy/dz by conv_mesh_refine_factor per pass, until the deepest S-parameter dips stabilize within the conv_* thresholds. Omit to use the project's saved setting.
--perf-mode||Performance-benchmark mode: keep mesh/domain at the chosen quality but loosen ringdown to a fixed -20 dB (1e-2 energy ratio) and disable the convergence study so a high-quality CPU run finishes in minutes instead of 30+ minutes.
--max-stepsMAX_STEPS|| Hard cap on this run's backend steps in either simulation mode. It does not change the stored auto_max_steps or adv_max_steps setting. If the cap is hit before ring-down, the time record is truncated before the fields settle, so the S-parameter and radiation results are not converged.
--ringdown-min-stepsRINGDOWN_MIN_STEPS|| Optional minimum step before energy ringdown may stop the run, above the built-in floor of two excitation lengths every run keeps. Zero adds nothing above that floor. Omit to use the project value, which defaults to 0.
--vram-budget-mbVRAM_BUDGET_MB|| Post-export memory budget in MB. The CLI reads the realized GPU VRAM or CPU RAM estimate for the selected backend and refuses before launch when it exceeds this value (writes a manifest with status='vram_overflow_predicted'). Applies in auto and advanced modes. Default: no budget check.
--no-surface-currents||Force-disable surface current capture regardless of the project's saved setting.
--no-nf2ff||Force-disable NF2FF far-field capture regardless of the project's saved setting. The far-field DFT is VRAM-resident and scales with the Huygens surface x frequency count, so skipping it on an S-parameter-only run avoids large VRAM use for results that are not needed.
--no-raw-fields||Force-disable all 3D field frame exports regardless of the project's saved setting.
--export-port-csv||Also write the raw port time-series CSVs (port_signals_raw.csv and the per-port voltage CSVs), for debugging and external post-processing. Off by default. The S-parameters are stored from the backend's sparams.csv either way.
--skip-geometry-export||Do not write geometry.vtk/geometry.vdb when NF2FF or 3D field export would normally request it. Useful for very large domains when the mesh is not needed.
--dry-run||Apply overrides, validate, export the case, and print its exact mesh dimensions, cell count, timestep, and memory, then stop before launching the backend. Exit 2 if validation finds a blocking error.
--per-face-bcFACE=TYPE[:MM][]Set a per-face boundary condition (repeatable). FACE is one of x_lo, x_hi, y_lo, y_hi, z_lo, z_hi. TYPE is PML, PEC, or PMC. An optional :MM sets a fixed gap from the geometry to that face, realized exactly as given and overriding the air margins there. Faces without :MM follow the air margins. Example: --per-face-bc z_lo=PEC:2.0. Any per-face setting forces bc_all to Custom. Always give PEC/PMC faces an explicit gap.
--mesh-preview-sizeMESH_PREVIEW_SIZE|| Pixel size of the mesh-preview PNG written by --export-mesh.
--save-after-run||After the run, save the updated project (in-place unless --save-as is given).
--save-asSAVE_AS|| Path to save the project as after the run (implies --save-after-run).
--record-history||Append the completed run to the project's GUI Run History rail. Off by default and does not imply --save-after-run.
--externalize-resultsproject / run / off|| Where to store run results when the project is saved. 'project' writes results to a sidecar .rfsimout next to the .rfsim and makes that the project's saved default (so the .rfsim can be committed and the .rfsimout gitignored). 'run' does the same for this run only without changing the saved default. 'off' keeps results inside the .rfsim. Omit to use the project's own setting.
--out-dirOUT_DIR|| Directory to write exports + run_manifest.json. Default: <project_dir>/_sim_result/<case>. With --folder, each project gets its own subdirectory here so no two runs share a manifest.
--export-sparamsall / s11 / s21 / noneallS-parameter CSV/PNG export selection.
--export-touchstone||Also write Touchstone (.s1p/.s2p).
--export-smith||Write Smith chart PNG.
--export-polar||Write polar radiation pattern PNG (E-plane + H-plane).
--polar-freq-mhzPOLAR_FREQ_MHZ|| Target frequency (MHz) for the polar plot. The nearest recorded pattern frequency is used. Default: the centre of the simulated band.
--export-rad3d||Write 3D radiation pattern PNG (PyVista off-screen).
--rad3d-freq-mhzRAD3D_FREQ_MHZ|| Target frequency (MHz) for the 3D radiation plot. The nearest recorded pattern frequency is used. Default: the centre of the simulated band.
--export-rad3d-vtk||Also write radiation pattern as a VTK/VTP file.
--export-rad-pattern||Write a flat radiation-pattern CSV (freq_hz,theta,phi,gain) from NF2FF data. Not a 3D render, so it runs under --no-3d-renders.
--export-mesh||Write mesh preview PNG (PyVista off-screen).
--export-mesh-vtk||Also copy geometry.vtk into the out dir.
--export-currents||Write surface-currents heatmap PNG at nearest frequency.
--currents-freq-mhzCURRENTS_FREQ_MHZ|| Target frequency (MHz) for surface currents. The nearest recorded frequency is used. Default: the centre of the simulated band.
--export-all||Convenience: enable every export artifact.
--no-3d-renders||Skip PyVista off-screen exports (mesh preview, rad3d).
--setVAR_SET[]Variable override name=value applied before the run (repeatable, parametric-studio).
--settingNAME=VALUE[]Set any FDTD setting by name (repeatable), gated by the same value gate as the GUI. An unknown name, bad type/enum, or hard-bound value exits 2. A soft-bound value prints one warning and runs as set. See machshev schema --what settings for the field list.

machshev sweep

Run the same strict sweep definition and sequential engine as the desktop app. By default state is kept under _sim_result and does not enter the GUI History rail. --record-history explicitly uses the project's History store.

The flags shared by every sweep subcommand:

FlagValueDefaultMeaning
--project, -pPROJECT|| Saved project (.rfsim).
--accountACCOUNT|| Remote runner account. Defaults to saved config.
--fingerprintFINGERPRINT|| Expected remote runner identity fingerprint.
--json||Emit machine-readable JSON events.

machshev sweep preview and machshev sweep run

preview validates and prints the mandatory per-point cost preview. run previews, persists state, and runs every sweep point. Both take the definition flags. run also takes the last three rows.

FlagValueDefaultMeaning
--definitionDEFINITION|| Strict SweepDefinition JSON/YAML file.
--axisNAME=V1,V2,...[]Inline list axis (repeat for a second axis).
--combinegrid / zip|| Two-axis combination (default: grid).
--all-ports||Drive every port at each point.
--backendcpu / cuda|| Sweep backend (default: cpu).
--targetTARGET|| local or remote:HOST:PORT (default: local).
--deviceDEVICE|| Runner device for a remote target: auto (default), cpu, or cuda:INDEX.
--name (run only)NAME|| Sweep name (default: project stem plus timestamp).
--state-dir (run only)STATE_DIR|| Durable CLI sweep-state directory. Default: project _sim_result.
--record-history (run only)||Write the sweep into the project's GUI Run History rail.

machshev sweep resume and machshev sweep retry

resume resumes failed or missing points from an exact saved base. retry retries one failed point from an exact saved base.

FlagValueDefaultMeaning
--sweep-idSWEEP_ID|| Persisted sweep id, such as s0001.
--state-dirSTATE_DIR|| CLI sweep-state directory used by the original run.
--record-history||Read the sweep from the project's GUI Run History rail.
--point-index (retry only)POINT_INDEX|| Zero-based failed point index to run again.

machshev network

Inspect, preview, or report port matching networks.

SubcommandFlagsMeaning
machshev network show--project, --port, --jsonThe resolved ladder per networked port, with the compiled companion at the project timestep. --port limits to one 1-based port number.
machshev network preview--project, --port, --jsonThe ladder's continuous and dt-companion two-port response, plus the predicted matched S11 when recorded results exist for the port.
machshev network report--project, --jsonRecorded per-part loss, totals, and the energy-balance residual from the last run.

--json emits a machine-readable machshev-network/v1 envelope.

machshev project

Build, import, inspect, or mutate a project.

machshev project build

Build a project from a spec file.

FlagValueMeaning
--specSPECSpec file (.json/.yaml).
--outOUTOutput project (.rfsim).

machshev project import and machshev project import-openems

import builds or extends a project from a strict board-import JSON spec. The spec explicitly selects detected or enumerated row roles, Gerber copper polarity, drill plating, the dielectric source, any undeclared DXF unit, the KiCad or openEMS destination, and optional project settings and authored shapes. Existing project and result-sidecar paths refuse unless --replace is set. import-openems imports openEMS / CSXCAD XML through the same strict assignment and destination contract, and requires format openems in the spec.

FlagValueMeaning
--specSPECBoard-import spec JSON (schema --what board-import).
--outOUTOutput project (.rfsim).
--replace|| Replace an existing output project and its result sidecar.
--json|| Emit the effective assignments and import report as JSON.

machshev project export-dxf

Export selected project layers and explicitly selected utility geometry to one DXF or one file per selection. Existing targets refuse unless --replace is set.

FlagValueDefaultMeaning
--projectPROJECT|| Saved project (.rfsim).
--outOUT|| Output DXF drawing (.dxf).
--replace||Replace an existing DXF drawing.
--json||Emit the structured DXF export report as JSON.
--layerLAYER[]Project layer name to export, repeatable. Defaults to all layers.
--separate||Write filename-[layer].dxf for each selected layer/utility.
--no-outline||Do not export the Board Outline utility layer or the board cutouts.
--no-ports||Do not export the Ports utility layer.
--no-drills||Do not export via drills or holes.

machshev project export-openems

Export supported project geometry, materials, vias, holes and cutouts, one active axis-aligned lumped port, boundaries, mesh, and a Gaussian band to openEMS XML. Unsupported electrical content refuses the whole export. Text output is one outcome plus actionable warnings, and --json retains structured details. An existing XML file refuses unless --replace is set.

FlagValueMeaning
--projectPROJECTSaved project (.rfsim).
--outOUTOutput openEMS XML file (.xml).
--replace|| Replace an existing openEMS XML file.
--json|| Emit the complete openEMS export report as JSON.

machshev mesh

Explain, print, or compare the exact realized mesh. Every subcommand takes --project / -p, --quality (a quality name or 0..3 to realize at, omitted uses saved settings), and --json.

SubcommandExtra flagsMeaning
machshev mesh explain|| Explain mesh regions, faces, cost, and timestep ownership. --quality reports an auto-derived override even for an advanced project. --json emits a machshev-mesh/v1 report.
machshev mesh lines--axis x / y / zPrint the exact mesh-line arrays a run will consume. --axis limits output to one axis. --json emits a machshev-mesh-lines/v1 document.
machshev mesh diff--against AGAINSTCompare mesh lines with a project, mesh-lines JSON, files.json, or case dir. Per-line drift up to 1e-12 of the smaller adjacent local pitch is treated as serialization noise. The report keeps the actual maximum delta. Fixed JSON and case lines are unchanged by --quality. --json emits a machshev-mesh-diff/v1 report.

machshev calc

RF transmission-line and antenna calculators (microstrip, patch with inset feed, quarter-wave, Smith, cpw, ...). Frequencies in GHz, lengths in mm, impedances in ohm.

FlagMeaning
calc_kindWhich calculator to run: microstrip / stripline / cpw / gcpw / diff / embedded / patch / lambda / lambda-diel / qwt / smith.
--freqFrequency (GHz).
--erSubstrate relative permittivity.
--hSubstrate height (mm).
--wStrip width (mm). Omit it to solve from --z0.
--z0Target/reference impedance (ohm). The patch feed and smith use 50 when it is omitted.
--sGap/spacing (mm) for cpw/gcpw/diff.
--bPlate spacing (mm) for stripline.
--tCopper thickness (mm) for stripline. Omitted, the result uses and prints 0.035 mm (1 oz). 0 is a strip of no thickness.
--h2Cover height (mm) for embedded microstrip.
--er2Cover permittivity for embedded microstrip.
--tandDielectric loss tangent. Given, the line calculators report dielectric loss. Omitted, the model runs lossless and prints no loss field.
--z1Source impedance (ohm) for qwt.
--z2Load impedance (ohm) for qwt.
--rResistance (ohm) for smith.
--xReactance (ohm) for smith.

Remote verbs

The serve and remote verb group runs and drives remote runner boxes. Setup walkthrough: Runner setup.

machshev serve

Run the remote-runner daemon.

FlagValueMeaning
--state-dirSTATE_DIRRunner state directory.
--nameNAMERunner name (default: computer name).
--ownerOWNEROwner account email. Only this account gets control, everyone else connects view-only.
--hostHOSTBind address (default 0.0.0.0).
--portPORTTCP port (default 8787).
--slotsSLOTSAt most this many jobs at once, on top of one job per device (default: one per exposed device).
--devicesDEVICESThe devices jobs may run on, as a comma-separated list of cpu and cuda:<index> (for example cpu,cuda:0). Omitted, the runner exposes every device this box can run on: the CPU when the CPU backend is present and each NVIDIA GPU when the CUDA backend answers. A job names one of them or auto, which takes the first free one, GPUs first. --install persists it to runner.json.
--backend-dirBACKEND_DIRDirectory containing the backend binary (searched first).
--advertiseADVERTISEauto (default), explicit host:port, or off.
--license-keyLICENSE_KEYAccount license key (or set MACHSHEV_LICENSE_KEY). A Pro account key licenses the runner with no seat consumed: the website signs a machine-bound token per job, and the same key registers with the broker for 'discover by account'. --install persists it to runner.json. The key is never sent to a peer.
--allow-unlicensed|| Development option for a trusted LAN: run jobs without the backend license gate on a runner with no activated license. Without this flag an unlicensed runner refuses to serve. The mode is reported to every connecting client in the handshake.
--open-owner|| Trusted-LAN option: with no --owner configured, grant owner control to any connecting peer instead of the default view-only role.
--install|| Generate identity + config, print fingerprint.
--autostart|| Also emit a run-on-startup service unit.
--health|| Print status JSON and exit.
--servers|| Print this box's hardware and current load, then exit.
--window|| Run the runner with a status window instead of the console. The editor's "Use this computer as a runner" button starts this.

machshev remote

Drive a remote runner. Every subcommand except describe-schema takes the connection flags --host HOST, --port PORT (default 8787), --fingerprint FINGERPRINT (pinned runner SPKI fingerprint, hex), and --account ACCOUNT.

SubcommandExtra arguments and flagsMeaning
machshev remote ls-jobs|| List jobs on a runner.
machshev remote statusJOB_IDJob status.
machshev remote info|| The runner's advertised hardware and version.
machshev remote submit--case-dir CASE_DIR, --spec SPEC, --meta META, --device DEVICE, --waitSubmit a pre-exported case dir. --spec is simulation runner JSON with only job_kind and device, --meta is metadata JSON, and --device is the runner device to run on: auto (a free device, GPUs first), cpu, or cuda:<index>. The runner queues the job until that device is free. --wait attaches and streams to completion.
machshev remote pollJOB_ID, --interval (default 5), --timeoutPoll status until terminal or timeout. --interval is seconds between status checks, --timeout gives up after this many seconds (0 = no limit).
machshev remote list-filesJOB_IDList a finished job's result files.
machshev remote fetchJOB_ID, --dest DEST, --artifacts auto / ports / pattern / mesh / currents / fields / allDownload results.
machshev remote cancelJOB_IDCancel a job.
machshev remote describe-schema|| Print the JobSpec / ExportSpec / telemetry contract (no connection).
