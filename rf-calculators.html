About these tools

The PCB Toolkit is the pcb_toolkit calculator library compiled to WebAssembly, so the website runs the same Rust code as its command line and desktop app. Antenna Studio is NEC Studio, a NEC-2 antenna modeling engine written in Rust, running in the same way. Both run entirely in your browser: nothing you type is sent anywhere.

pcb_toolkit by Alexander Kiselev and contributors, and nec-rs, are each licensed under either of the MIT License or the Apache License 2.0. The patch, inverted-F, quarter-wave, Smith chart and wavelength calculators on this page are closed forms with their references shown.
