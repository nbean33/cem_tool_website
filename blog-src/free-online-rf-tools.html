Two free tools are now on this site: the PCB Toolkit, with 50 PCB design calculators, and Antenna Studio, a NEC-2 antenna modeler. Neither needs an install or an account.

The same code as the desktop apps

Both tools began as desktop applications written in Rust. Rather than port their formulas to JavaScript, we compiled the original Rust code to WebAssembly, so the website runs the same calculator library and the same method-of-moments solver as the desktop builds. The interfaces are the desktop apps' own, restyled for the site.

Because everything runs in your browser, nothing you type is sent to a server. Once a page has loaded, it needs no further connection.

PCB Toolkit

The toolkit covers trace impedance (microstrip, stripline, coplanar and more), differential pairs, current capacity to IPC-2221A and IPC-2152, vias and padstacks, signal integrity, PDN impedance, crosstalk, and the everyday Ohm's-law family. A library of 45 laminates fills in the dielectric constant and loss tangent. Every calculator has its own link, such as tools/pcb/#impedance.microstrip.

Antenna Studio

Start from a template such as a dipole, a Yagi or a loop, change its dimensions, and the model is solved as you edit. The 3D view shows the current on each wire and the radiation pattern; the side panels show impedance, SWR, pattern cuts and a Smith chart. Frequency and parameter sweeps, a matching-network designer and an optimizer run in the background without freezing the page.

The browser solves on a single thread, so very large models are slower than on the desktop. For typical HF and VHF wire antennas, solves take well under a second.
