Questions

Do I need a card for the free check?

Whether a payment method is needed to sign up.

How is a full check priced?

Per board. Before it runs, the button shows how many connections it covers, about how long it will take, and the price.

Can I check a board again after fixing it?

Yes. Upload the new revision and the free check runs again.

Is my design safe?

Files are encrypted, deleted after a set period, and never reused. See Security and privacy.

Can we run it on our own servers?

Yes. Self-hosting is part of the Enterprise plan: the checks run inside your network and no board file is sent to us. Contact us to set it up.
